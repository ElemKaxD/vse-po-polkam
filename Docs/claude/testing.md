# Тестирование

1. `python Tools/rebuild.py` → «Проблем: 0».
2. `SHOTS_DIR=<scratchpad> python Tools/ui_tour.py`, склеить `Tools/grid.py` по 4 и **просмотреть глазами**:
   - ничего не растянуто; текст внутри кнопок и карточек; ничто не перекрывает важное (меню, панели, ценники);
   - поле уровня целиком на экране 16:9 (тележка с колёсами); облачко обучения не закрывает цель;
   - заголовки по центру своих лент; предметы ремонта стоят на земле или на здании, не в воздухе.
3. Уровни: `TOUR_LEVELS=3,11,46 python Tools/ui_tour.py game`; механики — `Tools/autoplay.py`.
4. Тесты правил: Test Runner → EditMode (14 тестов `Tests/RulesTests.cs`).
5. WebGL: сборка (см. tools.md), копия в scratchpad, `python -m http.server`, пройти уровни 1–3 кликами
   (обучение: рука на первой ячейке ленты; шаг «переложи из тележки» — хлеб виден и нажимается), выйти в хаб,
   купить вывеску, открыть карту.
