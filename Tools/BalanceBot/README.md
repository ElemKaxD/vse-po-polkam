# Бот-тестировщик «Всё по полкам!»

Сам играет в уровни через мост Unity MCP, собирает метрики и строит инфографику.

## Использование (Unity запущен)

```
python Tools/BalanceBot/bot.py --run 1 110 --shots   # прогон уровней (можно частями, резюмеится)
python Tools/BalanceBot/bot.py --econ                # снять экономику/каталог в JSON
python Tools/BalanceBot/bot.py --report              # собрать Temp/balancebot/report.html
```

Полный цикл: `--econ` один раз, `--run 1 110 --shots` (~10 минут), затем `--report`.
Прогон можно прервать (Ctrl+C) и продолжить — результат хранится в `Temp/balancebot/run.json`
и дописывается по уровням.

## Что собирает

- **run.json** — на каждый уровень: результат, ходы автоплея, холостые шаги (тупики), время.
- **econ.json** — предметы ремонта (цены по районам), товары магазина, константы экономики.
- **shots/** — скриншот каждые 10 уровней для визуального контроля.

## Что в отчёте (report.html)

1. Эффективность ходов: оптимум солвера / ходы бота по всем уровням (красное < 0.55 — очень плотно).
2. Средняя сложность по районам.
3. Покрытие механик: где вводится, сколько уровней использует.
4. Экономика: накопленный доход против расходов на ремонт по районам (красное — траты).
5. Скриншоты прогона.
6. Выводы: предупреждения (дисбаланс, ошибки консоли), выводы, чек-лист «чего не хватает».

Пороги эвристик — в начале `report.py` (0.55 / 0.9 для эффективности). Инфографика — matplotlib,
всё вшито в один HTML (base64), открывается браузером без сервера.
