# «Всё по полкам!» — проект Unity для Яндекс Игр

Unity 6000.4.1f1 · Built-in Render Pipeline · WebGL · плагин YG2 (PluginYourGames v2.0092)

## Сцены (всё лежит в сценах, ничего не генерируется при Play)

| Сцена | Что внутри |
|---|---|
| `Assets/AllOnShelves/Scenes/Boot.unity` | Загрузка: логотип, прогресс, объект `App` (сервисы). Первый запуск → сразу уровень 1, иначе → Hub |
| `Assets/AllOnShelves/Scenes/Hub.unity` | Стартовый экран, карта (200 ценников по дорогам 11 районов), ремонт (5 магазинов, 89 предметов), альбом, магазин покупок, ежедневки, лидерборды, окна |
| `Assets/AllOnShelves/Scenes/Game.unity` | Уровень: 2 ленты, стеллаж на 9 секций, тележка (5 мест + ящики грузчика), заказ, покупатель, HUD, обучение, окна победы/поражения/паузы/механики, «Час пик» |

Динамически создаются только товары на поле (префаб `Prefabs/ItemView.prefab`) — их набор задают данные уровня.
Любую сцену можно запустить Play напрямую: `Game` стартует уровень из поля `GameController → Editor Test Level`.

### Редактор интерфейса: правка в запущенной игре (29.09.2026)

1. Меню **«Всё по полкам → Редактор интерфейса»** (вкладка рядом с Inspector).
2. **«▶ Запустить игру для правки»**. Вверху кнопка «Середина игры» даёт монеты, звёзды и открытые районы.
3. Кнопками откройте нужное: экраны хаба, карту или ремонт любого района (ремонт — «ничего / половина / всё куплено»),
   окна хаба, **награды** (награда «Звёздного пути», пачка наклеек, окно победы на 1/2/3 звезды и после «×2»),
   любой уровень и его окна (поражение, пауза, новая механика, итоги «Часа пик», облачко обучения).
   Размер экрана можно переключать: 16:9, 21:9, 16:10, 4:3.
4. Выделите объект в окне Scene или Hierarchy и двигайте, растягивайте, масштабируйте мышкой
   (кнопка «Настроить окно Scene» включает 2D и инструмент Rect — клавиша **T**) или цифрами в инспекторе.
   Размер шрифта — в инспекторе текста.
5. **«Сохранить правки»**. После выхода из игры правки сами перенесутся в сцены и сохранятся при любой пересборке.
   Если забыли нажать — сохранится при выходе из игры.
   - Запоминается только то, что вы выделяли.
   - Если окно пишет «место этого объекта задаёт код» — двигайте его родителя (например, весь стеллаж или всю строку).
   - «Вернуть выделенное к раскладке из кода» забывает правку объекта (вернётся после пересборки сцен).

### Посмотреть и подвинуть любой экран или уровень мышкой (без запуска игры)

1. Меню **«Всё по полкам → Просмотр сцен и уровней»**. Окно откроется вкладкой рядом с Inspector.
2. Нажмите, что показать. Игру запускать не нужно: всё показывается в обычном режиме редактора.
   - **Уровень 1–200**, кнопки «+1 ход» / «+5» (ходы по решению уровня), «Первый уровень с механикой» (замки, коробки, морозилка, покупатель, две ленты…).
   - **Окна уровня**: победа, поражение, пауза, новая механика, обучение, «Час пик».
   - **Хаб**: стартовый экран, альбом, магазин, завоз дня, рейтинг, карта любого района, ремонт любого района («здание после ремонта», «все предметы»), окна хаба.
3. Кнопка «Настроить окно Scene для интерфейса» включает 2D и инструмент Rect (клавиша **T**). Двигайте и масштабируйте объекты мышкой в окне Scene, затем **Ctrl+S**.
4. **Правки сохраняются при пересборке сцен.** Перед сборкой запоминаются положение, размер, поворот, масштаб и размер шрифта каждого объекта (`Editor/Data/user_layout.json`). После сборки они возвращаются на место. Меню «Раскладка» умеет сохранить правки вручную, показать файл правок и забыть их.
   - Ленты, стеллаж и тележку на уровне тоже можно двигать. Их положение хранится отдельно для уровней с одной и двумя лентами (`Resources/BoardLayout.asset`).
   - Секции стеллажа расставляются автоматически по их количеству, поэтому двигайте стеллаж целиком.
   - Товары на поле временные и в сцену не сохраняются.
   - Объекты, добавленные вручную, при пересборке пропадут. О таком лучше скажите Claude.

## Где что лежит

- `Scripts/Core` — правила игры на чистом C# (без Unity): модель уровня, механики, солвер, генератор, план 200 уровней, экономика. Тесты: `Tests/RulesTests.cs` (Test Runner → EditMode, 14 тестов).
- `Scripts/Game` — сцена уровня. `Scripts/Hub` — экраны хаба. `Scripts/Services` — `GameApp` (прогресс, кошелёк, ремонт, альбом, ежедневки), `Platform` (весь SDK Яндекса), `MetaCatalog` (предметы ремонта, альбом, товары магазина — **цены и тексты правятся здесь**), `SaveData` (сейв в `YG2.saves`).
- `Resources/Levels/levels.json` — 200 уровней. Перегенерация вне Unity: `Tools/LevelTool` → `dotnet run -c Release -- 1 200 60` (отчёт `Tools/LevelTool/report.csv`).
- `Art` — нормализованная графика (скрипт `Tools/ArtPipeline/normalize_art.py`, исходники остаются в `yandex_games`).

## Как собрать билд (пошагово)

1. Открыть проект в Unity. Дождаться, пока внизу справа пропадёт крутилка «компиляция».
2. **Посмотреть на консоль** (Window → General → Console, кнопка «Clear» и красный значок ошибок).
   Если есть хоть одна красная ошибка — сборка не пойдёт и упадёт через несколько секунд
   с текстом `Error building Player because scripts had compiler errors`. Сначала чиним ошибки.
   Важно: ошибка может не показываться в редакторе, но вылезать в сборке — так бывает, когда код
   внутри `#if UNITY_EDITOR` используют снаружи. В редакторе всё работает, а билд падает.
3. Меню **«Всё по полкам → 2. Собрать сцены»** — только если что-то меняли в сценах или коде,
   который их строит. Если просто хотите собрать то, что есть, шаг можно пропустить.
4. Меню **«Всё по полкам → 3. Собрать WebGL для Яндекс Игр»**.
   Пункт сам переключит платформу на WebGL и поставит шаблон YandexGames.
   Первая сборка после смены платформы долгая (10–25 минут), дальше 3–8 минут.
   Unity в это время не отвечает — это нормально, ждать.
5. Результат:
   - папка `Builds/WebGL` — сама игра (её можно открыть локальным сервером и проверить),
   - архив `Builds/AllOnShelves_WebGL.zip` — **его и грузить в консоль Яндекс Игр**.
   - короткий итог сборки пишется в `Temp/build_result.txt`, например
     `Build Succeeded: 42,3 MB, 214s, errors 0`.

**Если сборка падает сразу (за 5–10 секунд)** — это всегда ошибки компиляции, смотрите консоль.
**Если падает в середине** — смотрите `Editor.log`
(`C:\Users\<вы>\AppData\Local\Unity\Editor\Editor.log`), искать слово `error`.

**Проверить сборку локально** — двойной щелчок по `Builds\Zapustit_igru.bat`: он поднимает сервер
именно в папке `Builds\WebGL` и сам открывает игру в браузере (`http://localhost:8123`). Окно сервера
не закрывать, пока играете. Двойной щелчок по `index.html` не работает: игра повиснет на заставке
с логотипом и пустой полосой — браузер не даёт ей читать файлы с диска. Сервер, запущенный из другой
папки (например, из корня проекта), тоже покажет только список файлов, а не игру.
Локально нет SDK Яндекса (`sdk.js 404` в консоли) — реклама, покупки и рейтинг работают только на Яндексе.

**Показать черновик издателю**: загрузить `Builds\AllOnShelves_WebGL.zip` в консоль Яндекс Игр, затем
«Пользователи и доступы» → «Добавить нового пользователя» → Яндекс ID издателя, роль с доступом
к черновикам (например, «Поддержка» — только просмотр, или «Разработчик»), выбрать игру → «Пригласить».

## Что нужно сделать в консоли Яндекс Игр

1. **Покупки** (Yandex Payments, нужен подключённый договор): создать товары с ID точно как в коде:
   `starter_pack`, `no_ads`, `coins_s`, `coins_m`, `coins_l`, `coins_xl`, `helpers_pack`, `undo_24h`, `theme_night`, `theme_winter`, `theme_farm`, `set_gold`,
   и новые для магазина из 5 вкладок (01.10.2026): `helpers_big` (Большой набор: 25 отмен + 15 подсказок, 179 ₽, расходуемый),
   `builder_pack` (Набор строителя: 4000 монет + 10 отмен + 5 подсказок, 199 ₽, расходуемый),
   `stickers_pack` (Набор коллекционера: 10 пачек наклеек + золотая, 99 ₽, расходуемый),
   `sets_all` (Все оформления: 4 набора разом, 399 ₽, постоянный).
   Цены (экономика v2, 30.09.2026): стартовый 99 ₽, без рекламы 199, монеты 49 / 129 / 299 / 599,
   помощник 79, отмены на сутки 49, наборы оформления: фермерский 129, новогодний 149, ночной 149, золотой 299.
   Постоянные (не расходуются в коде): `starter_pack`, `no_ads`, `theme_*`, `set_gold`, `sets_all`.
   Названия и описания — как в `MetaCatalog.Products` (Docs/claude/economy.md).
2. **Лидерборды** с техническими именами: `levels`, `stars`, `rush`, а для нового рейтинга (01.10.2026) — `day` и `week`
   (числовые, по убыванию). Таблицей по умолчанию оставить `stars`: в `day`/`week` в очки «вшит» номер дня/недели,
   на странице игры у Яндекса там были бы видны большие числа.
3. **Sticky-баннер** — включить в настройках рекламы (в игре он включается в хабе и выключается в уровне).
4. **Метрика**: указать номер счётчика в настройках плагина YG2 (`PluginYourGames/Resources/SettingsYG2` → Metrica), события уже отправляются (`level_start`, `level_win`, `level_lose`, `ad_rewarded`, `ad_interstitial`, `iap_purchase`, `meta_buy`, `album_pack`, `rush_end`).
5. Загрузить `Builds/AllOnShelves_WebGL.zip` в черновик, проверить рекламу и покупки на черновике.

## Реклама (ГДД 10)

- Interstitial: после победы («Дальше»), после поражения («Заново»/«На карту»), выход из паузы, конец «Часа пика». Не раньше 4-го уровня, не в первую минуту сессии, не чаще раза в 60 c, не раньше 45 c после rewarded. Отключается покупкой «Без рекламы».
- Rewarded (ID для аналитики): `reward_x2`, `reward_continue`, `reward_undo`, `reward_hint`, `reward_cart_plus`, `reward_chest2`, `reward_pack`, `reward_tips`, `reward_rush`.
- GameReady вызывается, когда показан первый интерактивный экран; Gameplay start/stop — на уровне/паузе/экранах результата.

## Отличия от ГДД (решения по ходу разработки)

| Где | ГДД | Сделано | Почему |
|---|---|---|---|
| «Грузчик» | уносит 3 товара | приносит 2 ящика: +2 места в тележке до конца уровня (как на кадре 07) | в тупике тележка почти всегда полна нужных для заказа товаров — вынос делал заказ невыполнимым, и кнопка почти никогда не показывалась |
| Паллета | остаток — в тележку | все 3 товара идут в выбранную секцию; раскупленная секция принимает остаток снова | проще и не требует места в тележке |
| Секция на стеллаже | спрайт `brd_section` | светлая плашка + 3 ячейки `brd_slot_outline` | на спрайте секции нарисовано 4 полки, товары не совпадали с ячейками |
| Вертикальный экран | отдельная раскладка | адаптивный масштаб: поле 16:9 целиком вписывается в любой экран | полная портретная раскладка — задача следующего этапа |
| Языки | RU, потом EN/TR | только RU | по плану ГДД — релиз на русском |
| Ленивая загрузка ассетов | бандлы по экранам | весь арт в сборке, сжатие crunch | размер сборки см. в отчёте сборки; при необходимости — Addressables |
| Сложность | 200 уровней по классам | 183 из 200 точно в целевом классе, остальные — легче цели | корректируется перегенерацией по метрикам после запуска |
| Звук | — | система готова, файлов нет | файлы генерируются в Suno по `Docs/AUDIO_PROMPTS_ВсёПоПолкам.txt` |
| Золотая карта, сезонные события | после релиза | не сделано | по плану LiveOps ГДД |

## Отладка

`GameController` содержит методы `DebugAutoMove` (ход солвера), `DebugRandomMove`, `DebugToCart`, `DebugUnlockInput` — используются скриптами `Tools/autoplay.py` и `Tools/unity_play.py` для автопрогона уровней.
Сейв в редакторе хранится плагином YG2 локально; сбросить — `PluginYourGames` → Set Default Saves.
